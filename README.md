# College Website 

This is a simple multi-page college website built using HTML5. The project is designed to provide basic information about the college, including home page, about section, services, registration, and contact details.

## 📌 Features
- Multi-page website structure
- Home page with college overview
- About page with institution details
- Services page
- Registration form page
- Contact page
- Simple and user-friendly navigation

## 🛠️ Technologies Used
- HTML5
- CSS3 (internal styling)

## 📁 Pages Included
- CodebindHOME1.html (Home Page)
- ABOUT.html
- SERVICE.html
- REGISTRATION.html
- CONTACT.html

## 🚀 How to Run
1. Download or clone the repository
2. Open `CodebindHOME1.html` in any web browser
3. Navigate through other pages using links
